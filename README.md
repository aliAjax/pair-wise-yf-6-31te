# 公共部位共担维修台

端口规划：`5114`

```bash
npm install
npm run dev
```

楼道、屋顶等公共部位维修按户共担。预置 101/102/201/202 四户与楼道感应灯、屋顶防水、外墙落水管三项事项。

## 业务规则

- 共担事项按户登记分摊比例，四户合计必须恰好为 100%，否则整次提交被拒绝，原分摊与缴款状态保持不变。
- 各户分别确认缴款；任一户未确认缴款前，事项不得标记为已完成。
- 某户退出时，须为余下各户重填比例且合计仍为 100% 才生效；否则保持原分摊。新分摊生效后缴款需重新确认。
- 费用统计（共担总额、已确认缴款、待收）与 localStorage 存档同步，每次变更即写入，刷新后保留。

## 文件划分

- `src/rules.js`：规则（比例校验、缴款/完工约束、费用统计），纯函数。
- `src/state.js`：状态（四户三项预置数据、所有变更入口）。
- `src/storage.js`：本地存档（localStorage 读写）。
- `src/main.js`：页面渲染与事件；`src/styles.css`：样式。

不新增页面，也不引入新依赖（仅 Vite）。
