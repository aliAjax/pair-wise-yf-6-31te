# 公共部位共担维修台

端口规划：`5114`

```bash
npm install
npm run dev
```

## 第二版闭环（公共部位共担维修）

- 预置四户（101/102/201/202 室）与三项共担事项（楼道感应灯、屋顶防水、单元门门禁）。
- 楼道、屋顶等共担事项按户登记分摊比例，**合计必须为 100%**；校验不通过则整次拒绝，原分摊与缴款状态保持不变。
- 各户分别确认缴款；**任一户未确认缴款前不得完工**。
- 某户退出须重填余下各户比例且仍合计 100%，否则保持原分摊；退出户原缴款记录失效，其余户缴款状态保留。
- 费用统计（预计费用合计、待缴分摊金额）与 localStorage 本地存档同步，刷新后保留。

## 文件分工

- `src/rules.js`：业务规则——状态口径、比例整批校验、缴款与完工前置条件（纯函数）。
- `src/state.js`：应用状态——预置数据、登记/缴款/开工/完工等状态变更。
- `src/storage.js`：本地存档——localStorage 读写与版本校验。
- `src/main.js`：单页界面与交互编排，不新增页面或依赖。
